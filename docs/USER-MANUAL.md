# 企业内部服务器资产管理系统用户手册

## 1. 文档说明

| 项目 | 内容 |
| --- | --- |
| 适用系统 | 企业内部服务器资产管理系统 |
| 适用版本 | v2.22 及当前主分支版本 |
| 适用对象 | 系统管理员、资产管理员、审批人、申请人 |
| 文档范围 | Web 端日常操作、业务流程、权限说明和常见问题 |

本系统用于管理服务器资产台账、资产发现、机房机柜、IP 地址、软件许可、服务器凭据、资产盘点和工单审批。不同用户看到的菜单和可执行操作由系统角色决定。

本手册中的“管理员”指系统角色为“管理员”的用户，不等同于操作系统管理员。

## 2. 登录与界面

### 2.1 访问系统

使用管理员提供的系统地址访问 Web 页面。开发环境默认地址为：

```text
http://localhost:5173
```

建议使用当前版本的 Chrome、Edge 或其他 Chromium 内核浏览器。

### 2.2 登录

1. 在登录页输入账号和密码。
2. 单击“登录”。
3. 登录成功后进入系统。

系统支持两类账号：

- 本地账号：由系统管理员创建，密码保存在本系统。
- AD 账号：由管理员从 AD 导入，登录时由 AD 验证密码，角色仍由本系统管理。

未导入系统的 AD 用户不能直接登录。被禁用的用户不能登录。

### 2.3 首次登录修改密码

本地用户首次登录时，系统可能要求修改初始密码：

1. 输入原密码。
2. 输入不少于 8 位的新密码。
3. 再次输入新密码。
4. 单击“确认修改”。
5. 使用新密码重新登录。

AD 用户不能在本系统修改 AD 密码。

### 2.4 退出登录

单击页面右上角的用户名，在下拉菜单中选择“退出登录”。

退出后当前会话立即失效。管理员禁用用户、用户修改密码或执行全端退出后，已有登录令牌也会失效。

### 2.5 二次认证

下载或恢复备份、查看凭据明文、查看许可证密钥等敏感操作可能弹出“二次认证”窗口。输入当前登录密码并验证成功后，系统会自动继续原操作。

二次认证只在限定时间内有效。AD 用户应输入当前 AD 密码。

## 3. 角色与权限

### 3.1 角色说明

| 功能 | 管理员 | 资产管理员 | 审批人 | 申请人 |
| --- | :---: | :---: | :---: | :---: |
| 数据看板 | 是 | 是 | 是 | 是 |
| 查看全部资产 | 是 | 是 | 否 | 否 |
| 查看本人负责资产 | 是 | 是 | 是 | 是 |
| 新增、编辑、删除、导入资产 | 是 | 是 | 否 | 否 |
| 资产发现、盘点、机房机柜、IP 地址池 | 是 | 是 | 否 | 否 |
| 凭据管理、软件许可 | 是 | 是 | 否 | 否 |
| 新建工单 | 是 | 是 | 是 | 是 |
| 审批工单 | 是 | 否 | 是 | 否 |
| 执行工单 | 是 | 是 | 否 | 否 |
| 验收本人申请的工单 | 是 | 否 | 否 | 是 |
| 工单报表 | 是 | 否 | 否 | 否 |
| 流程、用户、巡检、审计、备份、任务、系统配置 | 是 | 否 | 否 | 否 |

普通用户只能查看“资产归属”与本人账号或姓名匹配的资产。资产管理员和管理员可以查看全部资产。

工单详情、评论、附件和归档文件仅对申请人、相关审批人、执行人、资产管理员或管理员开放。

### 3.2 菜单显示

系统自动隐藏当前角色无权访问的菜单。菜单不可见通常表示当前账号没有该功能权限，不代表系统故障。

## 4. 数据看板

“数据看板”用于快速查看：

- 资产总数和在线、离线、未知数量。
- 资产类型分布。
- 最近资产发现趋势。
- 最近发现任务及新增、变更、离线数量。

看板数据遵循资产数据范围权限。普通用户看到的资产统计可能少于管理员。

## 5. 服务器资产

### 5.1 查询资产

进入“服务器资产”，可使用关键字和筛选条件查询资产。常用条件包括：

- IP 地址、主机名、资产编号。
- 资产类型、生命周期状态、在线状态。
- 资产归属、网段、机房和机柜。

单击“筛选”可调整筛选项，单击“列设置”可选择列表显示字段。单击资产行可查看详情、二维码和变更历史。

### 5.2 新增资产

管理员或资产管理员可以新增资产：

1. 单击“新增资产”。
2. 填写 IP 地址、主机名、MAC 地址、资产类型、操作系统和资产归属等信息。
3. 根据需要填写关联 IP、开放端口、运行服务、应用版本和机柜 U 位。
4. 单击“保存”。

关联 IP 使用逗号分隔。机柜 U 位可填写单个 U 位，例如 `12`；也可填写范围，例如 `12-14`。

### 5.3 编辑、批量编辑和删除

- 单项编辑：在资产行右侧单击“编辑”。
- 批量编辑：勾选资产后单击“批量编辑”，只有已勾选并填写的字段会被修改。
- 批量删除：勾选资产后单击“批量删除”，确认后执行。
- 退役资产：在资产详情中执行退役操作，资产状态变为“已退役”，历史记录继续保留。

删除和批量修改前应核对选择范围。重要资产优先使用“退役”，避免直接删除历史台账。

### 5.4 导入资产

1. 单击“下载模板”获取 Excel 模板。
2. 按模板表头填写数据，不要修改表头。
3. 单击“导入资产”并选择 CSV 或 XLSX 文件。
4. 等待系统返回导入结果。
5. 检查新增、更新和失败数量。

模板字段包括：

```text
序号、IP地址、主机名/设备名称、MAC地址、厂商、资产类型、操作系统、
开放端口、运行服务/应用、应用版本、资产归属/负责人、所在网段、备注
```

系统根据 IP 地址生成内部资产编号。编号不存在时新增，已存在时更新。导入文件不应加入“风险等级”字段。

### 5.5 导出和打印标签

- “批量导出”：导出与导入模板字段一致的 CSV。
- “报表导出”：导出资产统计数据。
- “打印标签”：勾选资产后生成二维码标签页面，可使用浏览器打印。
- 资产详情中的二维码可下载为 PNG。

二维码指向系统内资产详情。扫码用户仍需登录并具备资产查看权限。

### 5.6 资产状态

生命周期状态：

| 状态 | 含义 |
| --- | --- |
| 待上线 | 资产已登记但尚未投入使用 |
| 使用中 | 资产正常投入使用 |
| 维护中 | 资产处于维护状态 |
| 已退役 | 资产已退出使用但保留历史 |
| 已下线 | 资产已停止运行 |

在线状态由资产发现结果维护，分为“在线”“离线”“未知”，与生命周期状态相互独立。

## 6. 资产发现

该功能仅管理员和资产管理员可用，运行前服务器必须能够调用 nmap。

### 6.1 创建发现规则

1. 进入“资产发现”的“发现规则”页签。
2. 新建规则，填写规则名称和扫描目标。
3. 扫描目标可使用单个 IP、多个 IP 或 CIDR 网段。
4. 配置详扫端口、探活端口、服务识别和运行周期。
5. 根据风险控制要求选择自动纳管、自动应用低风险变更或自动生成工单。
6. 设置扫描时段、增量扫描等选项。
7. 保存规则。

大网段扫描会自动分片。单次目标数量受系统配置上限限制。

### 6.2 试运行和正式运行

- “试运行”用于检查规则和 nmap 是否可用。
- “立即运行”会创建正式发现任务并保存运行结果。

任务可能异步执行。可在“运行记录”或“任务运行中心”查看状态。

### 6.3 处理发现结果

发现结果包括：

- 新增：未匹配现有资产的主机。
- 变更：端口、服务版本、主机名或操作系统发生变化。
- 恢复在线：原离线资产重新被发现。
- 离线：超过离线时间窗口且跨规则确认未发现。
- 无变化：资产与现有台账一致。

处理步骤：

1. 打开对应运行记录。
2. 查看主机、变更类型、风险等级和差异摘要。
3. 勾选新增主机后执行“纳管”。
4. 勾选变更记录后执行“应用变更”。
5. 对高风险变化重点核对端口关闭、主机名、操作系统和服务版本变化。

自动应用只适用于规则允许的低风险变更。应用结果会写入资产快照和操作审计。

### 6.4 统计页签

“趋势统计”“网段分布”“端口/服务矩阵”用于观察发现结果趋势和网络资产分布，不直接修改资产。

## 7. 资产盘点

管理员和资产管理员可以创建盘点单：

1. 进入“资产盘点”。
2. 单击“新建盘点单”。
3. 填写名称，可按资产类型限定范围。
4. 创建后打开“盘点”。
5. 对每项资产标记“一致”或“盘亏”，必要时填写备注。
6. 完成核对后关闭盘点单。
7. 导出 CSV 差异报告。

关闭后的盘点单不应继续修改。关闭前应确认所有需要核对的资产均已处理。

## 8. 机房、机柜和 IP 地址

### 8.1 机房机柜

在“机房机柜”中先创建机房，再为机房创建机柜并设置 U 位数量。

删除机房会连带删除该机房下的机柜配置。执行删除前应确认资产台账中的机房、机柜文本字段是否需要调整。

### 8.2 机柜视图

在“机柜视图”中选择机房和机柜，可查看资产占用的 U 位。单击资产块可进入资产详情。

资产能否正确显示取决于资产台账中的机房、机柜和 U 位是否与机柜配置一致。

### 8.3 IP 地址池

在“IP 地址池”中维护网段名称、CIDR 和用途说明。打开使用情况可查看：

- 网段容量。
- 已使用和可用数量。
- 已使用 IP 及关联资产。

IP 地址池用于统计和冲突检查，不会自动修改资产 IP。

## 9. 凭据管理

该功能仅管理员和资产管理员可用。

1. 新建凭据，填写名称、类型、用户名、密码或密钥，并可关联资产。
2. 列表和详情不会直接返回明文。
3. 单击“查看”并确认后，按提示完成二次认证。
4. 查看行为会写入操作审计。
5. 使用结束后及时关闭明文窗口，不要截图或转发。

凭据删除后不可恢复。修改凭据时，敏感字段留空通常表示保留原值，应以页面提示为准。

## 10. 软件许可

该功能仅管理员和资产管理员可用。

### 10.1 维护许可证

新增或编辑时填写：

- 软件名、厂商和许可类型。
- 许可证密钥。
- 授权数量和已使用数量。
- 购买日期、到期日期。
- 关联资产和备注。

许可证密钥加密保存，列表不展示明文。查看密钥需要确认和二次认证，并写入审计日志。

### 10.2 导入导出

1. 下载许可证导入模板。
2. 按模板填写 CSV 或 XLSX。
3. 执行导入。
4. 系统按“软件名 + 厂商”匹配，存在则更新，不存在则新增。

导出的 CSV 不包含许可证密钥明文。

### 10.3 许可证附件

打开许可证的“附件”，可上传授权书、合同或扫描件，也可下载和删除。单个附件默认上限为 20 MB。

附件可能包含敏感商业信息，只应授予必要人员访问权限。

### 10.4 到期处理

系统会检查即将到期和已过期许可证，并根据配置发送通知。到期许可证还可能自动生成“软件许可续费”草稿工单。

## 11. 工单流程

### 11.1 工单类型

- 资产登记
- 资产变更
- 资产下线/报废
- 权限/维护申请
- 定期巡检
- 软件许可续费

### 11.2 工单状态

```text
草稿 -> 审批中 -> 已审批 -> 执行中 -> 待验收 -> 已关闭
                  |
                  +-> 已驳回 -> 修改后重新提交
```

补充操作：

- 审批中的工单可由申请人撤回到草稿。
- 草稿或已驳回工单可取消。
- 审批人可驳回工单。

### 11.3 新建和提交

1. 进入“工单流程”。
2. 单击“新建工单”。
3. 选择工单类型、关联资产和优先级。
4. 填写申请原因、变更内容和影响评估。
5. 单击“保存草稿”。
6. 在列表中单击“提交”。

对应工单类型必须已配置并启用审批流程，否则无法提交。

### 11.4 审批

审批人在“我的待办”中处理工单：

1. 打开工单详情，核对申请内容、关联资产、附件和审批进度。
2. 单击“通过”或“驳回”。
3. 填写处理备注并确认。

一个审批节点配置多个审批人时，任一审批人通过即可完成该节点。审批人可将当前审批任务转交给其他管理员或审批人。列表支持批量审批符合条件的待办工单。

管理员可在用户管理中为审批人设置代理审批人，代理人可以处理其待办。

### 11.5 执行和验收

1. 工单全部审批通过后，管理员或资产管理员单击“开始”。
2. 完成实际操作后单击“完成”，填写执行结果。
3. 工单进入“待验收”。
4. 申请人核对结果后单击“验收”。
5. 验收通过后工单关闭。

资产登记、变更或退役工单关闭时，相关信息可能写回所有关联资产，并生成资产快照和审计记录。

### 11.6 评论和附件

工单参与人可在详情中：

- 追加评论。
- 上传附件。
- 下载有权限访问的附件。
- 查看审批步骤和操作时间线。

附件和评论属于工单审计资料，不应上传与工单无关的敏感文件。

### 11.7 SLA

流程启用审批时限或完成时限后，工单列表显示剩余时间或超时时间。系统会扫描超时工单并按配置发送邮件或 IM 通知。

### 11.8 归档

工单验收关闭后，系统使用模板和 LibreOffice 生成 PDF：

- 在工单详情中下载单个归档 PDF。
- 勾选多个已关闭且已归档工单，批量下载 ZIP。

只有工单参与人或管理员可以下载归档。归档未生成时，应由管理员检查 LibreOffice、模板路径和任务运行状态。

## 12. 管理员功能

### 12.1 流程配置

1. 进入“流程配置”。
2. 选择工单类型。
3. 设置流程名称和启用状态。
4. 根据需要设置审批时限和完成时限。
5. 新增审批节点并选择审批人。
6. 使用“上移”“下移”调整节点顺序。
7. 保存流程。

流程变更只应由业务负责人确认后执行。修改正在使用的流程前，应评估在途工单影响。

### 12.2 用户管理

管理员可以：

- 新建本地用户。
- 修改姓名、邮箱、部门和角色。
- 启用或禁用用户。
- 重置本地用户密码。
- 设置代理审批人。

禁用用户会使其现有会话失效。AD 用户密码不能在本系统修改。

### 12.3 AD 域控

在“系统配置 > AD 域控”中：

1. 填写 LDAP 地址、Base DN、Bind DN 和 Bind 密码。
2. 配置登录名属性和用户过滤条件。
3. 保存后执行连接测试。
4. 按登录名查询用户。
5. 核对用户信息并导入。
6. 在“用户管理”中分配系统角色。

AD 只负责认证，不会自动赋予管理员或审批权限。

### 12.4 邮件通知

在“系统配置 > 邮件通知”中填写 SMTP 主机、端口、TLS、用户名、密码和发件地址。保存前可向测试收件人发送测试邮件。

邮件失败不会自动改变业务操作结果。应结合任务中心和服务日志排查。

### 12.5 IM 通知

在“系统配置 > IM 通知”中：

- 选择钉钉、企业微信或飞书。
- 填写机器人 Webhook 和可选加签密钥。
- 启用并发送测试消息。
- 根据需要配置回调验签参数。
- 维护 IM 用户标识与系统用户的绑定关系。

群机器人通知与 IM 内直接审批是不同能力。直接审批需要平台自建应用、可访问的 HTTPS 回调地址和正确的验签配置。

### 12.6 巡检规则

1. 进入“巡检规则”并新建规则。
2. 设置每日、每周或每月执行周期。
3. 设置执行时间和执行人。
4. 填写巡检内容并启用。
5. 使用“试运行”立即生成测试巡检工单。

正式调度会自动生成巡检草稿工单，后续仍需按配置流程提交和审批。

### 12.7 工单报表和操作审计

- “工单报表”展示状态、类型、优先级、趋势和 SLA 指标，并支持 CSV 导出。
- “操作审计”可按实体和动作筛选关键操作，查看操作人、对象、详情和时间。

审计日志用于追溯，不应作为普通业务数据随意清理。

### 12.8 数据备份

“数据备份”创建的是包含数据库、附件、工单归档和配置的加密完整备份。

推荐操作顺序：

1. 单击“立即备份”。
2. 等待备份创建完成。
3. 单击“校验”，确认完整性校验通过。
4. 确认存在异地副本或将备份下载到受控位置。

恢复操作：

1. 选择已校验的备份。
2. 单击“恢复”。
3. 完成二次认证。
4. 确认恢复提示。
5. 在维护窗口重启后端。
6. 登录系统核对数据库、附件、归档和配置。

恢复会覆盖当前数据。恢复前必须先为当前环境创建新备份，并停止业务写入。

### 12.9 任务运行中心

任务中心展示资产发现、SLA、巡检建单、维保提醒、许可提醒和完整备份任务。

管理员可以：

- 按任务类型和状态筛选。
- 查看执行节点、来源、尝试次数、结果和错误。
- 打开任务详情。
- 重试失败任务。
- 确认已处理的失败任务。

重试前应先处理错误原因。外部程序缺失、目录不可写或配置错误时，直接重复重试通常仍会失败。

## 13. 安全使用要求

- 首次登录后立即修改初始密码。
- 不共用账号，不通过聊天工具传递密码、密钥或备份。
- 只为用户授予完成职责所需的最低角色。
- 查看凭据或许可证密钥后及时关闭窗口。
- 下载的附件、归档和备份应保存在受控目录。
- 禁止将生产数据库和真实配置上传到公共代码仓库。
- 离岗、调岗或账号异常时，管理员应及时禁用用户。
- 发现未知登录失效、权限变化或敏感数据被查看时，应检查操作审计。

## 14. 常见问题

### 14.1 登录失败

检查：

1. 账号和密码是否正确。
2. 用户是否已启用。
3. AD 用户是否已导入系统。
4. AD 服务是否可用。
5. 是否因连续失败触发临时登录限制。

### 14.2 页面提示无权限

确认当前用户角色和数据范围。普通用户只能查看本人负责的资产和本人参与的工单。

### 14.3 工单无法提交

常见原因：

- 工单仍缺少必要信息。
- 对应工单类型没有启用审批流程。
- 流程没有有效审批节点或审批人。
- 当前用户不是申请人或管理员。

### 14.4 工单归档无法下载

确认：

- 工单状态为“已关闭”。
- 归档编号已经生成。
- 当前用户是工单参与人或管理员。
- LibreOffice 和归档模板可用。
- 任务运行中心没有相关失败记录。

### 14.5 资产扫描失败

确认：

- nmap 已安装并可执行。
- 扫描目标和端口格式正确。
- 服务运行账号有执行 nmap 的权限。
- 防火墙允许扫描。
- 目标数量没有超过系统上限。
- 任务运行中心和运行记录中的错误信息。

### 14.6 邮件或 IM 没有收到

1. 使用系统配置中的测试发送功能。
2. 检查 SMTP、Webhook、TLS 和密钥。
3. 检查收件人邮箱和垃圾邮件目录。
4. 检查任务运行中心和服务日志。

### 14.7 备份恢复后数据未变化

恢复请求只会标记待恢复，必须重启后端后才会应用。重启后仍未生效时，检查备份校验结果、文件目录权限和后端启动日志。

### 14.8 登录突然失效

以下情况会使会话失效：

- 用户主动退出。
- 用户密码被修改。
- 管理员禁用用户。
- 用户执行全端退出。
- 会话被撤销或令牌到期。

重新登录失败时联系系统管理员。

## 15. 支持信息

反馈问题时应提供：

- 发生时间。
- 当前账号和角色，不提供密码。
- 页面名称和操作步骤。
- 页面错误提示。
- 相关资产编号、工单编号或任务 ID。
- 必要时提供脱敏截图。

不要在问题描述中提交密码、许可证密钥、AD Bind 密码、JWT 密钥、配置加密密钥或完整生产备份。
